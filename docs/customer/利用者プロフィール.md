# 利用者プロフィール（架空）

「家族の買い物リスト」を使っている1家族の概要。人物はすべて仮名で、実在しない。

- 家族構成：共働きの夫婦と子ども1人の3人。
  - Aさん（夫）：会社員。平日の帰りにスーパーへ寄ることが多い。
  - Bさん（妻）：会社員。土曜の買い出しと、週の献立を考える担当。
  - Cさん（子・小学5年生）：おやつや文房具を自分でリストに足す。
- 使っている端末：台所の壁に掛けた共用タブレット1台。リストはこのタブレットのブラウザにだけ保存されている。
- 今の使い方：気づいた人がタブレットに品目を足す。買い物に出る人がタブレットのリストをスマホで撮影して持っていき、帰宅後にタブレットで「買った」にチェックを入れる。
- 入力の癖：Aさんは英字キーボードのまま打つことがあり、「Milk」「milk」のように大文字と小文字が混ざる。Bさんは音声入力を使い、品目の末尾に空白が付くことがある（例：「牛乳 」）。
- 困りごと：同じ品目が2行に増え、片方だけチェックが付く。残った方を見て、すでに買った物をもう一度買ってしまう。直近では牛乳を夫婦それぞれが買った。
- 要望：家族それぞれのスマホでも同じリストを見たい。ただし、まずは2回買いをなくしたい。
- 利用歴：2026年8月から利用。問い合わせは9月から10月に5件。
