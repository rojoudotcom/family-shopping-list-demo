# 会社情報：株式会社デモ食品マート（架空）

> この会社・数値・人物はすべて研修用の架空の設定です。実在の企業とは関係ありません。

- **事業**：地域密着の食品スーパーマーケットチェーン。生鮮食品と日用品を扱う
- **店舗数**：約20店舗（同じ県内に集中）
- **会員数**：約5万世帯（無料の会員サービスに登録した家族単位）
- **会員サービス**：ポイント、チラシ配信、家族の買い物リストアプリ
- **買い物リストアプリを提供する理由**：買い忘れと二重買いを減らし、「この店で買えば迷わない」と感じてもらうため。来店のたびにアプリを開く習慣をつくりたい
- **気にしている指標（KPI）**
  - 会員アプリの利用継続率（登録から3か月後も週1回以上開いている世帯の割合）
  - 買い物リストアプリの週あたり利用世帯数
  - 会員アンケートの満足度（5段階）
- **担当部署**：会員サービス部（アプリの企画・会員の声の集約）、店舗運営部（店頭での案内・売り場との連携）
- **私たちとの関係**：買い物リストアプリの開発を当社チームに委託している
