# PRD：同じ品をまとめる

## なぜ作るのか（解決したい課題）

同じ品が2行になり、夫婦のどちらかが同じ物を2回買ってしまう。

- 2行になる原因は、入力の揺れである。「Milk」と「milk」、音声入力で末尾に空白が付いた「牛乳 」と「牛乳」が、別の行になる。

## 誰のためか

Aさん（夫）として、英字のまま品を打っても、同じ品が2行にならないようにしたい。
それは、残っている行を見て「まだ買っていない」と思い、2回買うことを防ぐためだ

Bさん（妻）として、音声入力で品を足しても、同じ品が2行にならないようにしたい。
それは、音声入力をやめずに、同じ品を1行で見られるようにするためだ

## 何を作るのか

- 同じ名前の品を足しても、行が増えない。大文字・小文字の違いと、前後の空白の違いは、同じ品として扱う。

### やらないこと

- チェック済みの品を足したとき、その行を「まだ買っていない」に戻すこと。次の段階にする。理由：行が増えないことを先に1つ届けるため。
- 買った品をリストの末尾へ移すこと。次の段階にする。理由：行が増えないことを先に1つ届けるため。
- 家族の端末どうしで同じリストを見る仕組み。次の段階にする。理由：2回買いをなくすことを先にすれば十分と、AさんもBさんも答えたため。
- 同じ品だったために行が増えないとき、画面で知らせること。理由：行が増えないことで十分に伝わるため。
- 全角と半角の違い（「ＭＩＬＫ」と「MILK」など）や、ひらがなとカタカナの違い（「ぎゅうにゅう」と「ギュウニュウ」など）を、同じ品として扱うこと。別の品のままにする。理由：表記の違いまでまとめると、別の物を1つにしてしまうおそれがあるため。

## 受け入れ条件

- [ ] 「牛乳」がリストにあるとき、「牛乳」を足しても、行は増えない
- [ ] 「milk」がリストにあるとき、「Milk」や「 milk 」を足しても、行は増えない
- [ ] 「牛乳」がリストにあるとき、「卵」を足すと、「卵」の行が増える
