# PRD：同じ品をまとめる

## なぜ作るのか（解決したい課題）

同じ品目が2行になり、2回買いが起きている。2週間で3件の「2行になった」記録があり、原因は次の2つだった。

- 大文字と小文字の違い（「Milk」と「milk」）、前後の空白（「牛乳 」と「牛乳」）で、別の品目として扱われる。
- チェック済みの品目と同じものを足すと、新しい行が増える。チェック済みの行は見ないので、増えたことに気づけない。

行が2つあると、どちらを信じればよいか分からない。

## 誰のためか

Aさん（夫）として、英字のまま入力しても、同じ品目が2行にならないようにしたい。
それは、入力のしかたを変えずに、同じ物を2回買わないためだ

Bさん（妻）として、音声入力で足した品目が、すでにある品目と1行になってほしい。
それは、買ったかどうかをひと目で分かるようにして、同じ物を2回買わないためだ

## 何を作るのか

- 品目を足すとき、大文字と小文字の違い、前後の空白だけが違う名前は、同じ品目として1行にまとめる。
- チェック済みの品目と同じものを足したときは、新しい行を増やさず、前からある行を「まだ買っていない」状態に戻す。
- チェックを付けた（買った）品目は、リストの末尾へ移す。理由：Zoom の投票でこの見せ方に決まったため。

やらないこと

- 家族の端末どうしで同じリストを見る仕組み（次の段階にする）。
- すでに2行になっている品目を1行にまとめ直すこと。理由：利用者が消せば済むため。
- 「卵」と「たまご」のように、読みや表記が違う品目を同じ品目として扱うこと。理由：別の物を1つにしてしまうおそれがあるため。

## 受け入れ条件

- [ ] 「milk」がある状態で「Milk」を足すと、行は増えない
- [ ] 「牛乳」がある状態で「牛乳 」（末尾に空白）を足すと、行は増えない
- [ ] 「 牛乳」（先頭に空白）を足しても、「牛乳」の行は増えない
- [ ] 「卵」にチェックが付いた状態で「卵」を足すと、行は増えず、その行のチェックが外れて「まだ買っていない」状態で表示される
- [ ] まだチェックのない「牛乳」がある状態で「牛乳」を足しても、行は増えない
- [ ] 「牛乳」がある状態で「卵」を足すと、「卵」の行が増える
- [ ] 「牛乳」にチェックを付けると、「牛乳」の行がリストの末尾へ移る

## 決まっていないこと

- なし
