# PRD：同じ品物を1行にまとめる

## なぜ作るのか（解決したい課題）

同じ品物がリストに2行できて、家族が同じ物を二度買ってしまう。会員の声6件のうち3件がこの話で、最も多い困りごとである（会員の声 No.1〜3、2026-10-19 の打ち合わせ）。

2行になる場面は次の3つである。

- 大文字と小文字の違い（「Milk」と「milk」）
- 音声入力で末尾に入る空白の違い（「牛乳」と「牛乳 」。見た目は同じ）
- 買ってチェックを付けた品物を、もう一度入れたとき（卵）

## 誰のためか

家族で買い物をする会員として、同じ品物をリストに二度入れても1行のままにしたい。
それは、同じ物を二度買ってしまうのを防ぐためだ

## 何を作るのか

- 品物を追加するとき、大文字と小文字の違い、前後の空白の違いを無視して、すでにある品物と同じかどうかを調べる
  - 理由：二重買いの声が6件中3件あり、見た目が同じでも別の行になる例が出たため（2026-10-19）
- すでにある品物と同じなら、新しい行を作らない
- 同じ品物の行にチェックが付いているときは、新しい行を作らず、その行を「まだ買っていない」状態に戻す
  - 理由：同じ物は一つの行だけにでき、店頭でも説明しやすいため（2026-10-19、DさんとEさんが賛成）

- 買った物（チェックを付けた品物）は、リストの末尾に移す
  - 理由：Zoom の投票で決まったため
- 同じ品物を足したときは、メッセージを出さず、行を増やさないだけにする
  - 理由：回答に理由の記載がなかった

やらないこと

- ひらがなとカタカナ、全角と半角の違いを、同じ品物として扱うこと
  - 理由：読みや表記の違いまでまとめると、別の物を1つにしてしまうおそれがあるため
- すでに別の行になっている品物を、あとから1行にまとめること
  - 理由：すでにある行は会員が消せば済むため
- 家族の端末どうしで同じリストを見る仕組み
  - 理由：端末をまたいでデータをそろえる仕組みが必要で、今回の範囲より大きいため。次の段階にする（依頼、2026-10-05、2026-10-19）

## 受け入れ条件

- [ ] 「牛乳」がすでにあるリストに「牛乳」を足すと、行は増えない
- [ ] 「Milk」がすでにあるリストに「milk」を足すと、行は増えない
- [ ] 「牛乳」がすでにあるリストに、末尾に空白を付けた「牛乳 」を足すと、行は増えない
- [ ] 「牛乳」がすでにあるリストに、先頭に空白を付けた「 牛乳」を足すと、行は増えない
- [ ] チェックが付いた「卵」がある状態で「卵」を足すと、行は増えず、その「卵」のチェックが外れる
- [ ] チェックが付いた「卵」がある状態で「卵」を足すと、「あと N 品」の数が1つ増える
- [ ] リストにない品物を足すと、これまでどおり新しい行が1つ増える
- [ ] 品物にチェックを付けると、その行がリストの末尾に移る
- [ ] 同じ品物を足したとき、「すでにあります」などのメッセージは出ない
- [ ] 同じ品物を足してブラウザを再読み込みしても、行は1つのままで、チェックの状態も保たれている

## 決まっていないこと

- [ ] チェックを外した（まだ買っていない状態に戻した）行を、リストのどこに置くか（選択肢：A. 末尾に残す／B. まだ買っていない物の並びの末尾に出す／C. チェックを付ける前の位置に戻す）
