# PRD：同じ品目を1行にまとめる

## なぜ作るのか（解決したい課題）

同じ品目が2行になり、夫婦のどちらかが同じ物を2回買ってしまう。

- 2行になる原因は2つある。1つは入力の揺れで、「Milk」と「milk」、音声入力で末尾に空白が付いた「牛乳 」と「牛乳」が別の行になる。もう1つは、買ってチェック済みの品目をまた足すと、新しい行が増えることだ。
- この2週間で、牛乳が2回、卵が1回、2行になった。9月には、片方にだけチェックが付いた牛乳の行を見て、夫が牛乳をまた買ってきた。
- チェック済みの行はふだん見ないため、行が増えたことに気づけない。

## 誰のためか

Aさん（夫）として、英字のまま品目を打っても、同じ品目が2行にならないようにしたい。
それは、残っている行を見て「まだ買っていない」と思い、2回買うことを防ぐためだ

Bさん（妻）として、音声入力で品目を足しても、同じ品目が2行にならないようにしたい。
それは、音声入力をやめずに、買ったかどうかを1行でひと目で分かるようにするためだ

## 何を作るのか

- 品目を足したとき、すでにある品目と大文字・小文字の違い、または前後の空白だけが違う場合は、新しい行を増やさず1行にまとめる。
- チェック済みの品目と同じ品目を足したとき、新しい行を増やさず、前からある行を「まだ買っていない」状態に戻す。
- 買った（チェックを付けた）品目は、一覧から隠さず、リストの末尾に残す。理由：Zoom の投票で決まったため。

### やらないこと

- 家族の端末どうしで同じリストを見る仕組み。次の段階にする。理由：2回買いをなくすことを先にすれば十分と、AさんもBさんも答えたため。
- すでにある品目と同じだったために行が増えないとき、画面で知らせること。理由：行が増えないことで十分に伝わるため。
- 全角と半角の違い（「ＭＩＬＫ」と「MILK」など）を、同じ品目としてまとめること。別の品目のままにする。理由：表記の違いまでまとめると、別の物を1つにしてしまうおそれがあるため。
- ひらがなとカタカナ、漢字の違い（「ぎゅうにゅう」と「牛乳」など）を、同じ品目としてまとめること。別の品目のままにする。理由：表記の違いまでまとめると、別の物を1つにしてしまうおそれがあるため。

## 受け入れ条件

- [ ] 「milk」がある状態で「Milk」を足すと、行は増えない
- [ ] 「牛乳」がある状態で「牛乳 」（末尾に空白）を足すと、行は増えない
- [ ] 「牛乳」がある状態で「 牛乳」（先頭に空白）を足すと、行は増えない
- [ ] 「牛乳」がまだ買っていない状態で、もう一度「牛乳」を足すと、行は増えない
- [ ] 「卵」にチェックが付いている状態で「卵」を足すと、行は増えず、その行のチェックが外れて「まだ買っていない」に表示される
- [ ] 「卵」にチェックが付いている状態で「卵」を足すと、「あと N 品」の数が1つ増える
- [ ] 「牛乳」にチェックを付けると、「牛乳」の行がリストの末尾に表示される
- [ ] 違う品目（「牛乳」と「卵」）を足すと、それぞれ別の行になる
