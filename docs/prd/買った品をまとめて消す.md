# PRD：買った品をまとめて消す

## なぜ作るのか（解決したい課題）

買い物のあと、チェックを付けた行がリストに残り続ける。消すには行ごとに「削除」を押すしかなく、手間なので消されない。

- 残った行の間に、まだ買っていない品が埋もれる。見落として、買い忘れが起きる。

## 誰のためか

Bさん（妻）として、買い物から帰ったら、チェックを付けた行をまとめて消したい。
それは、1行ずつ「削除」を押す手間をなくすためだ

Aさん（夫）として、まだ買っていない品だけを見て買い物をしたい。
それは、チェック済みの行に埋もれた品を見落とさないためだ

## 何を作るのか

- 「買った品を消す」ボタンを1つ置く。押すと、チェックを付けた行がまとめて消える。まだ買っていない品の行は、同じ順で残る。

### やらないこと

- 消す前に確かめる画面と、消したあとに元に戻す操作。次の段階にする。理由：まとめて消せることを先に1つ届けるため。
- チェックを付けた行を、自動で消すこと。理由：Aさんは、1週間に何を買ったかを見返してから消したいため。消すのは、ボタンを押したときだけにする。
- 買った品をリストの末尾へ移すこと。次の段階にする。理由：まとめて消せることを先に1つ届けるため。
- 家族の端末どうしで同じリストを見る仕組み。次の段階にする。理由：買い忘れをなくすことを先にすれば十分と、AさんもBさんも答えたため。

## 受け入れ条件

- [ ] チェックを付けた行が2つあるとき、「買った品を消す」を押すと、その2行が消える
- [ ] まだ買っていない品の行は、消えずに同じ順で残る
- [ ] チェックを付けた行が1つもないとき、押してもリストは変わらない
