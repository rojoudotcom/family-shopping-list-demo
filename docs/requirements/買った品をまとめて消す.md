# 要件定義書：買った品をまとめて消す

元の PRD：docs/prd/買った品をまとめて消す.md

## 1. 目的

チェックを付けた行がリストに残り続け、まだ買っていない品が埋もれて買い忘れが起きる課題をなくす。
「買った品を消す」ボタンで、チェックを付けた行をまとめて消せるようにする。

## 2. 使う人と場面

- Bさん（妻）として、買い物から帰ったら、チェックを付けた行をまとめて消したい。それは、1行ずつ「削除」を押す手間をなくすためだ
- Aさん（夫）として、まだ買っていない品だけを見て買い物をしたい。それは、チェック済みの行に埋もれた品を見落とさないためだ

## 3. 機能要件

- FR-01 「買った品を消す」ボタンを押すと、チェックを付けた行がすべて消える
- FR-02 まだ買っていない品の行は消えず、並び順も変わらない
- FR-03 チェックを付けた行が1つもないときは、押してもリストは変わらない

## 4. 受け入れ条件

- AC-01 前提 「牛乳」「卵」「パン」があり、「卵」と「パン」にチェックが付いている／操作 「買った品を消す」を押す／結果 「卵」と「パン」の行が消える
- AC-02 前提 「牛乳」「卵」「パン」「りんご」があり、「卵」にだけチェックが付いている／操作 「買った品を消す」を押す／結果 「牛乳」「パン」「りんご」が、この順で残る
- AC-03 前提 「牛乳」「卵」があり、どちらにもチェックが付いていない／操作 「買った品を消す」を押す／結果 リストは変わらない

## 5. 例外と境目

- 消すのは、ボタンを押したときだけ。チェックを付けただけでは、行は消えない
- 残った行の名前・チェックの有無・id は変えない
- 絞り込み（すべて／まだ買っていない／買った）のどれを表示していても、消すのはチェックを付けた行すべて

## 6. 非機能要件

- 消す処理は `src/listStore.js` の純粋関数に置き、DOM に依存させない
- 保存は今までどおり `localStorage` で行い、保存の形は変えない
- `test/unit/` にユニットテスト（node:test）を足し、`npm test` と `npm run lint` が通る
- 素の HTML・CSS・JavaScript のまま作り、フレームワークやビルド工程を足さない（README の方針）

## 7. 前提と対象外

前提：

- 今のアプリは、行ごとの「削除」でしか行を消せない（`src/listStore.js` の `deleteItem`）

対象外（今回は作らない）：

- 消す前に確かめる画面と、消したあとに元に戻す操作
- チェックを付けた行を、自動で消すこと
- 買った品をリストの末尾へ移すこと
- 家族の端末どうしで同じリストを見る仕組み

## 8. 決まっていないこと

PRD から引き継ぐものは、ありません。
