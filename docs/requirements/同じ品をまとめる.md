# 要件定義書：同じ品をまとめる

元の PRD：docs/prd/同じ品をまとめる.md

## 1. 目的

同じ品が2行になり、夫婦のどちらかが同じ物を2回買ってしまう課題をなくす。
同じ名前の品を足しても、行が増えないようにする。大文字・小文字の違いと、前後の空白の違いは、同じ品として扱う。

## 2. 使う人と場面

- Aさん（夫）として、英字のまま品を打っても、同じ品が2行にならないようにしたい。それは、残っている行を見て「まだ買っていない」と思い、2回買うことを防ぐためだ
- Bさん（妻）として、音声入力で品を足しても、同じ品が2行にならないようにしたい。それは、音声入力をやめずに、同じ品を1行で見られるようにするためだ

## 3. 機能要件

- FR-01 すでにある品と同じ名前の品を足すと、行は増えない
- FR-02 名前を比べるとき、大文字・小文字の違いと、前後の空白の違いは、同じ名前として扱う
- FR-03 違う名前の品を足すと、今までどおり新しい行が増える

## 4. 受け入れ条件

- AC-01 前提 「牛乳」がリストにある／操作 「牛乳」を足す／結果 行は増えない
- AC-02 前提 「milk」がリストにある／操作 「Milk」や「 milk 」を足す／結果 行は増えない
- AC-03 前提 「牛乳」がリストにある／操作 「卵」を足す／結果 「卵」の行が増える

## 5. 例外と境目

- 行が増えないとき、前からある行は変えない。名前の表記も、チェックの有無も、そのまま残る（「milk」の行に「Milk」を足しても「milk」のまま）
- チェック済みの品と同じ名前を足しても、行は増えず、チェックも付いたまま（チェックを外す動きは対象外）
- 比べるときに除くのは、前後の空白だけ。名前の途中の空白は、そのまま比べる
- 空白だけの入力は、今の動作のとおり「品名を入力してください」と拒否する（`src/listStore.js` の現状）

## 6. 非機能要件

- 名前の比べ方は `src/listStore.js` の純粋関数に置き、DOM に依存させない
- 保存は今までどおり `localStorage` で行い、保存の形は変えない
- `test/unit/` にユニットテスト（node:test）を足し、`npm test` と `npm run lint` が通る
- 素の HTML・CSS・JavaScript のまま作り、フレームワークやビルド工程を足さない（README の方針）

## 7. 前提と対象外

前提：

- 今のアプリは、品を足すと名前の前後の空白だけを除いて、同じ名前でも常に新しい行を足す（`src/listStore.js` の `addItem`）
- すでに保存されているデータには手を入れない。前から2行になっている品は、そのまま残る

対象外（今回は作らない）：

- チェック済みの品を足したとき、その行を「まだ買っていない」に戻すこと
- 買った品をリストの末尾へ移すこと
- 家族の端末どうしで同じリストを見る仕組み
- 同じ品だったために行が増えないとき、画面で知らせること
- 全角と半角の違い、ひらがなとカタカナの違いを、同じ品として扱うこと

## 8. 決まっていないこと

PRD から引き継ぐものは、ありません。
