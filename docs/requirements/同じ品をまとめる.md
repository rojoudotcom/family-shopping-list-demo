# 要件定義書：同じ品目を1行にまとめる

元の PRD：docs/prd/同じ品をまとめる.md

## 1. 目的

同じ品目が2行になり、夫婦のどちらかが同じ物を2回買ってしまう課題をなくす。
入力の揺れ（大文字・小文字、前後の空白）や、チェック済みの品目の再入力で行が増えないようにする。

## 2. 使う人と場面

- Aさん（夫）として、英字のまま品目を打っても、同じ品目が2行にならないようにしたい。それは、残っている行を見て「まだ買っていない」と思い、2回買うことを防ぐためだ
- Bさん（妻）として、音声入力で品目を足しても、同じ品目が2行にならないようにしたい。それは、音声入力をやめずに、買ったかどうかを1行でひと目で分かるようにするためだ

## 3. 機能要件

- FR-01 品目を足したとき、すでにある品目と大文字・小文字の違い、または前後の空白だけが違う場合は、新しい行を増やさず1行にまとめる
- FR-02 チェック済みの品目と同じ品目を足したとき、新しい行を増やさず、前からある行を「まだ買っていない」状態に戻す
- FR-03 買った（チェックを付けた）品目は、一覧から隠さず、リストの末尾に残す
- FR-04 違う品目は、それぞれ別の行にする

## 4. 受け入れ条件

- AC-01 前提 「milk」がリストにある／操作 「Milk」を足す／結果 行は増えない
- AC-02 前提 「牛乳」がリストにある／操作 「牛乳 」（末尾に空白）を足す／結果 行は増えない
- AC-03 前提 「牛乳」がリストにある／操作 「 牛乳」（先頭に空白）を足す／結果 行は増えない
- AC-04 前提 「牛乳」がまだ買っていない状態でリストにある／操作 もう一度「牛乳」を足す／結果 行は増えない
- AC-05 前提 「卵」にチェックが付いている／操作 「卵」を足す／結果 行は増えず、その行のチェックが外れて「まだ買っていない」に表示される
- AC-06 前提 「卵」にチェックが付いている／操作 「卵」を足す／結果 「あと N 品」の数が1つ増える
- AC-07 前提 リストに「牛乳」がある／操作 「牛乳」にチェックを付ける／結果 「牛乳」の行がリストの末尾に表示される
- AC-08 前提 リストが空、または違う品目だけがある／操作 「牛乳」と「卵」を足す／結果 それぞれ別の行になる

## 5. 例外と境目

- 全角と半角の違い（「ＭＩＬＫ」と「MILK」など）は、別の品目のままにする（PRD で対象外と決まっている）
- ひらがな・カタカナ・漢字の違い（「ぎゅうにゅう」と「牛乳」など）は、別の品目のままにする（PRD で対象外と決まっている）
- 空白だけの入力は、今の動作のとおり「品名を入力してください」と拒否する（`src/listStore.js` の現状）

## 6. 非機能要件

- 品目の判定と並びの変更は `src/listStore.js` の純粋関数に置き、DOM に依存させない
- `src/app.js` は DOM の配線だけを担当し、保存は今までどおり `localStorage` で行う
- `test/unit/` にユニットテスト（node:test）を足し、`npm test` と `npm run lint` が通る
- 素の HTML・CSS・JavaScript のまま作り、フレームワークやビルド工程を足さない（README の方針）

## 7. 前提と対象外

前提：

- 今のアプリは、品目を足すと名前の前後の空白だけを除いて、常に新しい行を足す。チェックを付けても行は元の位置のまま動かない（`src/listStore.js`、`src/app.js`）

対象外（今回は作らない）：

- 家族の端末どうしで同じリストを見る仕組み（次の段階にする）
- すでにある品目と同じだったために行が増えないとき、画面で知らせること
- 全角と半角の違い（「ＭＩＬＫ」と「MILK」など）を、同じ品目としてまとめること
- ひらがなとカタカナ、漢字の違い（「ぎゅうにゅう」と「牛乳」など）を、同じ品目としてまとめること

## 8. 決まっていないこと

PRD の「決まっていないこと」は「今のところ、ありません」だった。次の点は PRD に書かれていないため、人に尋ねる。

- 「Milk」を足して「milk」の行にまとめるとき、行に表示する名前は、前からある行の表記のままでよいか
- 品目の途中の空白（「牛乳 パック」と「牛乳 パック」など）は、同じ品目としてまとめるか
- 今の保存データに、すでに2行になっている同じ品目がある場合、まとめ直すか、そのままにするか
- 「すべて／まだ買っていない／買った」の絞り込みのとき、「リストの末尾」はどう見えればよいか
- 買った品目が複数あるとき、末尾の中での並び順（チェックを付けた順か、足した順か）をどうするか
- チェックを外した品目は、元の位置に戻すか、別の場所に置くか
