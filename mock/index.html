PRD：買った品をまとめて消す

GitHub の Issue #8 に登録済み・かんばん：Todo

AI が書いています…

PRD の下書きAI が作成

なぜ作るのか

買い物のあと、チェックを付けた行がリストに残り続ける。消すには行ごとに「削除」を押すしかなく、手間なので消されない。 残った行の間に、まだ買っていない品が埋もれて、買い忘れが起きる。問い合わせ5件のうち3件がこの困りごと。

誰のためか

Bさん（妻）として、買い物から帰ったら、チェックを付けた行をまとめて消したい。それは、1行ずつ「削除」を押す手間をなくすためだ。
Aさん（夫）として、まだ買っていない品だけを見て買い物をしたい。それは、チェック済みの行に埋もれた品を見落とさないためだ。

何を作るのか

  • 「買った品を消す」ボタンを1つ置く。押すと、チェックを付けた行がまとめて消える。

やらないこと

  • 消す前に確かめる画面と、元に戻す操作
  • チェックを付けた行を自動で消す（Aさんは見返してから消したい）

受け入れ条件

  • AC-01チェックを付けた行が2つあるとき、「買った品を消す」を押すと、その2行が消える
  • AC-02まだ買っていない品の行は、消えずに同じ順で残る
  • AC-03チェックを付けた行が1つもないとき、押してもリストは変わらない

決まっていないこと

今のところ、ありません。
